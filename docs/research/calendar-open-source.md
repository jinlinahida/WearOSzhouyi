# 四柱历法依赖调研

候选库：[6tail/lunar-java](https://github.com/6tail/lunar-java)。

- 仓库 README 说明它是无第三方依赖的 Java 公历/农历/节气/干支/八字库，并提供 Maven 坐标 `cn.6tail:lunar:1.7.7`。
- 仓库许可证为 MIT；本项目只通过公开 API 调用，不复制其源码，并在发布说明中保留归属。
- 文档明确区分立春按日期还是按精确交接时刻、节气按日期还是交接时刻，以及晚子时日柱“算明天”与“算当天”两种流派。

本项目采用精确节气交接时刻的年柱/月柱口径，暂采用晚子时日柱算明天的八字口径；真太阳时和地理位置修正不启用。该选择在 `SixTailGanzhiCalendar` 的构造参数中显式表达，后续可以替换而不影响装卦算法。
