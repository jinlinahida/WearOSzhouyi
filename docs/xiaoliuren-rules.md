# 小六壬规则口径

本项目第一版采用常见的“报时起课法”：六宫固定顺序为大安、留连、速喜、赤口、小吉、空亡；以农历月、农历日、时辰顺序起课，计数包含起始宫。正月从大安起，月宫再作为初一的起点，日宫再作为子时的起点。时辰编号按地支顺序子=1、丑=2……亥=12，仍采用包含起点计数，所有结果以六取余循环。

设备公历时间只通过现有 `Solar -> Lunar` 历法适配器得到农历月、日及时支；不将公历字段直接代入算法。晚子时沿用项目历法适配器的日柱约定，但小六壬时辰本身只使用子至亥的地支编号。

参考：传统起课说明 [壹读](https://read01.com/oEKJ5nP.html)、[六曜说明](https://zh.wikipedia.org/wiki/%E5%85%AD%E6%9B%9C)。资料对掌位描述略有差异，本实现只采用上述六宫顺序和“月上起日、日上起时”的可复现口径，不混用其他流派的速喜起月或特殊时刻规则。
