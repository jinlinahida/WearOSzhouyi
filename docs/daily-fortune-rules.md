# 今日运势规则

今日运势是对单个自然日的传统历法式呈现，不面向具体事项占断。所有输出都是「设备时区公历日期」的纯函数：不含任何随机数，同一天任意时刻打开结果一致，23:59 与次日 00:01 分属不同日。

## 日界与取样

- 以设备时区的公历日期为日界：先取 `instant.atZone(zoneId).toLocalDate()`。
- 所有历法查询固定在该日 12:00（午时）取样，经 Solar → Lunar 流程换算，避免晚子时口径歧义。四柱日干支、节气月柱、喜神/贵人方位、黄道吉时均以该取样点为准。

## 主卦与寄语：固定历元 384 日轮值

- 历元 EPOCH = 1984-01-31，这是一个真实甲子日，经 6tail `Solar.fromYmd(1984, 1, 31).getLunar().getDayInGanZhi()` 断言为「甲子」，并由 `HexagramRotationTest` 锁定。
- `dayIndex = 当日 epochDay − EPOCH epochDay`；`rotationIndex = floorMod(dayIndex, 384)`。
- 主卦按周文王卦序（`HexagramCatalog.zhouOrderCodes`）一卦值六日：主卦 = 第 `rotationIndex / 6` 卦；值日爻 = `YaoPosition.entries[rotationIndex % 6]`，初爻到上爻逐日递进。384 天恰好覆盖 64 卦 × 6 爻不重不漏。
- 卦级寄语取离线资料的 coreMeaning 与 advice；爻级寄语取该值日爻的爻辞。资料缺失时对应字段为空，不影响其余字段。

## 幸运色与数字：日干五行生克

- 取当日日干五行：生我者 = 幸运色，同我者 = 辅助色，克我者 = 忌色。
- 生克表为本功能自建小表，不改动纳甲规则：生 木→火→土→金→水→木；克 金克木、木克土、土克水、水克火、火克金。
- 五色表：木→青绿、火→红、土→黄、金→白、水→黑。
- 幸运数字 = 生我之行的河图生成数：水 1/6、火 2/7、木 3/8、金 4/9、土 5/10。

## 方位与吉时：6tail lunar 黄历数据

- 经 `DailyAlmanacSource` seam 调用 6tail lunar 1.7.7 的日级接口：喜神方位 `getDayPositionXi()/getDayPositionXiDesc()`，阳贵人方位 `getDayPositionYangGui()/getDayPositionYangGuiDesc()`。seam 层把库返回的八卦名映射为引擎 `Direction` 枚举。
- 吉时取当日十二时辰中天神为黄道六神（青龙、明堂、金匮、天德、玉堂、司命）者，承载地支、时间段与天神名。晚子时（23:00–23:59）作为独立条目照常参与过滤。
- 方位枚举与罗盘后天八卦口径对齐（`docs/compass-data-conventions.md`）：坎北 0°、艮东北 45°、震东 90°、巽东南 135°、离南 180°、坤西南 225°、兑西 270°、乾西北 315°。
- 喜神、贵人方位的歌诀体系出自《协纪辨方书》所载日干神煞方位传统；本项目按 6tail 的口径取数，不自行改表。

## 宜忌：十二建除

- 公式：`建除序号 = (日支序号 − 节气月支序号 + 12) % 12`。月建必须是节气月支，即四柱月柱地支（`DivinationTimeInfo.monthGanzhi.earthlyBranch`），不是农历月。日支与月支相同之日为「建」，此后逐日递进：建、除、满、平、定、执、破、危、成、收、开、闭。
- 建除随节气换月而切换，测试与 6tail `getZhiXing()` 对拍（含立春换月前后）。
- 宜忌词为随附的传统语义简表（如 建 = 宜上任/出行/谒贵，忌大动土），随 `JianChu` 枚举内置。
