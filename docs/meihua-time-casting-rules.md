# 梅花易数·时间起卦规则

本项目当前只实现“时间起卦”。页面打开时读取一次设备公历时间和设备时区，转换为农历、四柱后固定该结果；用户点按“重新按当前时间起卦”才会再次读取时间。

## 取数

- 年数：农历年干支的地支序数（子 1 至亥 12）。这是农历年，不以四柱中按节气切换的年柱替代。
- 月数、日数：农历月、日数字。闰月沿用该月的常规 1 至 12 数字，不额外加数。
- 时数：当前时辰地支序数（子 1 至亥 12）。
- 上卦 = 年 + 月 + 日；下卦 = 年 + 月 + 日 + 时；动爻也使用年 + 月 + 日 + 时。
- 卦数除以 8，余 1 至 7 对应乾、兑、离、震、巽、坎、艮，余 0 按坤（8）处理。
- 动爻除以 6，余 1 至 5 对应初爻至五爻，余 0 按上爻（6）处理。

## 派生卦与体用

- 本卦由上、下经卦组成；每一条线均按初爻到上爻保存，界面按上爻到初爻显示。
- 变卦只翻转该动爻的阴阳。
- 互卦以下互取本卦二、三、四爻，上互取三、四、五爻。
- 动爻落在的经卦为用卦，另一经卦为体卦。本项目固定采用这一口径，不混用其他资料的体用判法。

本功能仅呈现传统象数结构与现有离线通用卦义，不输出面向具体事项的确定性吉凶结论。
